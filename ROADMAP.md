# Roadmap

This roadmap outlines the planned milestones for `@sye1321/nestjs-chapa` to reach a stable 1.0 release, as defined in the technical specification.

- **M0 - Specification**: Approved architecture, public boundary, preliminary endpoint matrix.
- **M0.5 - Contract verification**: Direct provider probes, sanitized fixture pack, evidence-state updates.
- **M1 - Repository foundation**: Governance files, package skeleton, CI, build proof, release preview.
- **M2 - Core infrastructure**: Configuration, one-attempt transport, request executor, errors, validation, logging.
- **M3 - Payments**: Initialize, verify, cancel, references.
- **M4 - Refunds and metadata**: Create/verify refunds, banks, currencies.
- **M5 - Webhooks**: Raw-body verification, event parsing, Express/Fastify examples.
- **M6 - Release candidate**: Docs, consumer tests, security review, protected sandbox smoke.
- **M7 - Stable 1.0**: Public npm and GitHub release.
