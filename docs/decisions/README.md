# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records for `@sye1321/nestjs-chapa`.

## Process
- ADRs are used for material architecture, public API, compatibility, security, reliability, dependency, or release-policy decisions that are not already fixed by the technical specification.
- Accepted ADRs are immutable. Do not rewrite them to change history.
- If a decision changes, a new ADR must be proposed that supersedes the old one.
- ADRs cannot silently contradict the technical specification. Any conflict with the specification must stop implementation and be escalated for resolution.

To propose a new ADR, copy `0000-adr-template.md` and follow its instructions.
