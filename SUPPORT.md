# Support

## Getting Help
If you have a question, need help with using the SDK, or suspect a bug, please use the following mechanisms:

- **GitHub Issues**: Use our issue tracker to report bugs or request features.
- **Search**: Before opening a new issue, search existing open and closed issues to see if your question has already been answered.
- **Security Vulnerabilities**: **DO NOT** open public issues for security vulnerabilities. Suspected vulnerabilities must be reported confidentially following [SECURITY.md](SECURITY.md) via GitHub Private Vulnerability Reporting.

Please note that this is a community-maintained project. Support is provided on a best-effort basis.
